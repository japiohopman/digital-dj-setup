# Digital DJ Setup

A mobile-first digital DJ workspace inspired by classic Technics turntables and DMC battle layouts.

## Project status

The repository is being bootstrapped. Product work is tracked in GitHub Issues and delivered in small pull requests.

## Development

The app scaffold and local development instructions will be added in [Issue #1](https://github.com/japiohopman/digital-dj-setup/issues/1).

## Workflow

- One scoped issue per implementation pull request.
- Work on feature branches; do not develop directly on `main`.
- Keep one active feature pull request at a time.
- Run lint, typecheck, tests, and production build before requesting review.
- Keep visual deck components separate from the Web Audio engine.
